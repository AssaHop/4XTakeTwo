## Что сделано

### 1. Движение авиации (#28 закрыт)

`classTemplates.js`: добавлен `modules: ['Air']` в AAF, ADB, ATB.

`Air`-модуль в `navigationModules.js` выставляет `unit.ignoresObstacles = true`,
что `getAvailableHexes()` уже понимал (`const blocked = !isAllowed && !this.ignoresObstacles`).
Авиация теперь может лететь через любой террейн — реализует баланс-решение
"короткая дальность = самолёт должен физически подлететь к цели".

### 2. Ветеранство / weaponUnlocks

**`mechanics/units.js`** — конструктор: добавлены три поля:
```js
this.veteranLevel  = 0;
this.kills         = 0;
this.weaponUnlocks = options.weaponUnlocks ?? {};
```

**`core/combatLogic.js`**:
- `getAttackDamage()`: фильтрует `weType` по `weaponUnlocks[w] <= veteranLevel`
  перед перебором оружий.
- `performAttack()`: при убийстве инкрементирует `attacker.kills`,
  обновляет `attacker.veteranLevel` (пороги: 1/3/6 килов → уровни 1/2/3).

**`mechanics/units.js:getAttackableHexes`** (статический метод): аналогичный
фильтр по `weaponUnlocks`/`veteranLevel` перед перебором оружий.

**`core/classTemplates.js`** — WBB получил `weaponUnlocks`:
```js
weType: ['Main', 'Small'],
weaponUnlocks: { Small: 1 }  // Small unlocks at veteranLevel >= 1
```
Ветеран-линкор при первом кило получает частичное ПВО (Small, ×0.5 по air).

### 3. WLC → Amphibious

WLC переопределён как единственный юнит с движением по воде И суше:
```js
modules: ['Sail', 'Navy', 'Dual']
```
- Sail: +surf+water, moRange-1
- Navy: +deep, moRange+1 (итого moRange = template = 3)
- Dual: +land

Финальный moveTerrain: `['surf', 'water', 'deep', 'land']`.
Роль: захват береговых точек, amphibious assault.

Характеристики скорректированы: `hp: 5, atDamage: 2, dangerScore: 20`
(слабее в бою, но уникальная мобильность).

### 4. Win/lose условия (#1, #1a закрыты)

**`scenarios/dominator.js`**: исправлены `winCondition`/`loseCondition` —
убран несуществующий `u.alive` (мёртвые юниты уже удалены из `state.units`):
```js
winCondition:  (state) => !state.units.some(u => u.owner?.startsWith('enemy')),
loseCondition: (state) => !state.units.some(u => u.owner === 'player1'),
```

**`core/game.js`**: в `initGame()` добавлены:
```js
state.scenario = getScenarioById(scenarioName);
state.gameOver = false;
```

**`ui/events.js`**: добавлена `checkEndConditions()`:
- Проверяет `state.scenario.winCondition/loseCondition`
- При срабатывании: `state.gameOver = true` + `setTimeout(() => alert(...), 50)`
- Вызывается после атаки игрока и после каждого хода AI в `runAISequence`
- `handleCanvasClick` и `handleEndTurn` блокируются при `state.gameOver`

### 5. ASP + DC weapon type

**`core/modules/weaponTypes.js`** — новое оружие `DC` (Depth Charge):
```js
DC: { range: 3, damageVs: { sub: 1.0 } }
```
Только против `targetClass: 'sub'`. Нет `surface`/`air` ключей = физически
не может выбрать такие цели.

**`core/classTemplates.js`** — новый юнит ASP:
```js
ASP: {
  hp: 6, atDamage: 3, moRange: 4, viRange: 8,
  weType: ['DC'], targetClass: 'surface',
  modules: ['Sail', 'Navy'], dangerScore: 15,
  aiProfile: { role: 'scout', risk: 0.4 }
}
```
- moRange: 4 → после Sail(-1)+Navy(+1) = 4
- viRange: 8 — лучший обзор среди кораблей (роль разведчика)
- atDamage: 3 — ровно убивает WSB за один удар (WSB hp=3)
- Не добавлен в dominator.js fleet — пользователь добавит вручную когда нужен
